Little Learner's Club — Phase 4 · approved hybrid

The Storybook Geometry system

Graphic Clubhouse construction, Modern Storybook warmth, Soft Clay's squish on touch. One strict system: everything below is either a global token (immutable) or a module theme variable (the only sanctioned flexibility). If it isn't a token, it doesn't ship.

01 — The contract

Immutable — the brand

  • Ink #31281C, canvas cream #FAF3E7, surface, paper, border
  • Brand terracotta — reserved for primary actions & brand moments
  • Feedback trio colors (helpful / mixed / needs-more-context)
  • Source Serif 4 display · Source Sans 3 UI — no third face, ever
  • Type scale, spacing scale, radius scale, 44px touch floor
  • Character construction grid, proportions, skin ramp, 2px ink line
  • Little Motions timing & easing tokens, celebration limits
  • Layout of the lesson template, choice cards, narration bar
  • Vocabulary: practised / exploring / ready to review · never scored

Flexible — the module

  • One accent hue (+ its strong & soft steps) per module world
  • Scene tint & tint-deep — the wash behind that module's scenes
  • One motif shape (petal circle, pixel square, compass diamond…)
  • Landmark composition, built from the shared scenery kit
  • Lesson content: narration, prompts, choices, missions
  • Character wardrobe colors (drawn from the module accent steps)
A module may change five variables and its content. Nothing else. A screen that needs a sixth variable is a design-system change request, not a local override.

Skin ramp — fixed, six steps, used verbatim

Module accent rules

  • One hue per module. Accent, accent-strong, accent-soft are three lightness steps of the same hue.
  • accent ≥ 3:1 against canvas (non-text use: landmarks, progress fill, play button).
  • accent-strong ≥ 4.5:1 on surface — the only step allowed to carry text.
  • Accents never impersonate the feedback trio or brand terracotta.
  • Adjacent modules on the map may not share a hue family.
  • Wardrobe colors come from the accent steps, so characters visibly belong to the place they're visiting.
  • No gradients anywhere — the single exception is Glim's radial glow.

Rules

  • Serif = voice of the story (titles, prompts, celebrations, parent editorial headings). Sans = everything functional.
  • Child-facing text never below body-500 (19px). Parent floor is body-300 (14px).
  • Weights: serif 600 only; sans 400 and 600 (700 reserved for chips ≤ 12px).
  • No italics for children; italic serif allowed for parent "worth talking about" quotes.
  • Line length ≤ 26ch child, ≤ 64ch parent. text-wrap: pretty everywhere.
  • No third typeface, no decorative faces, no all-caps sentences.

Nesting rule: a child element's radius = parent radius − parent padding, clamped to the scale. Full circles are reserved for character heads, map nodes, and the play button — never for buttons.

Surface & elevation

  • Level 0 — canvas cream. The app floor.
  • Level 1 — surface card: 1px border + shadow-soft 0 1px 2px / 0 4px 12px ink 4–6%.
  • Level 2 — paper-offset: a solid paper layer shifted +6px x/y behind the card. One per screen, hero moments only.
  • Overlay — scrim ink 40%, dialog at level 1.
  • No hard black shadows, no glows (except Glim), no stacked level-2s, no borderless floating cards.

05 — Illustration, characters, environments, icons

Character proportions

1 head
1.6 heads
2.6 heads tall · eyes at 45% · 2px ink line · limbs = rounded capsules

Character rules

  • Head is a perfect circle; body a rounded block; limbs capsules. All on a 4px grid.
  • Kids are 2.6 heads tall; adults 3.4; Glim 1.6. Nobody towers.
  • Faces: dot eyes, one 2px mouth stroke, optional 2px brows, optional blush. Emotion lives in eyes + brows + mouth + pose — never face distortion.
  • Skin from the six-step ramp, hair from a fixed set; wardrobe from module accent steps.
  • 2px ink outline on every character and foreground prop. Background scenery is outline-free.
  • Poses are limb rotations + a ±4° body tilt. No squash beyond 6% (that budget belongs to Little Motions).

Icon rules

  • 24px grid, 2px ink stroke, rounded caps and joins, ≤ 2 shapes per icon.
  • Active state = filled with module accent (nav) or brand (global) — plus a label, never icon-only.
  • No perspective, no detail smaller than 2px, no emoji.

Environment construction — 6 layers, always

  1. Wash — module tint fills the scene panel (radius-xl).
  2. Far shapes — tint-deep, big soft silhouettes, no outline.
  3. Landmark & props — module accent + soft step, 2px ink outline, built from the kit: circle, block, capsule, diamond, arch.
  4. Ground band — paper tone with a 2px ink top rule.
  5. Characters — standing on the ground band.
  6. UI — narration bar, prompts, cards. Never inside the scene.
Max 3 accent-hue elements per scene. The motif shape may repeat as decoration (≤ 5 instances). Complex final art is an illustrator deliverable — layout ships with kit scenes, marked as placeholders.

Celebration limits

  • Lesson celebration ≤ 600ms of motion; module ≤ 1200ms. Then still.
  • ≤ 8 particles, drawn from the module motif shape, one emission, no loop.
  • One celebration per achievement — replayable by the child's tap, never auto-repeated.
  • Audio (later) ≤ −14 LUFS, one soft cue, no fanfare stacking.
  • Celebration never gates the next action; "Back to the neighborhood" is live immediately.

Reduced-motion rules

  • Every transform animation swaps to an opacity fade ≤ 240ms.
  • Celebrations become a static badge + visible progress change.
  • Idle loops, parallax, and anticipation twitches switch off entirely.
  • Character reactions become expression swaps (eyes/mouth state change).
  • Meaning must survive: what changed is always carried by text, icon, or position — motion only ever decorates it.
