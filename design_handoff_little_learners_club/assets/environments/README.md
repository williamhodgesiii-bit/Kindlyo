# assets/environments/

Final scene / landmark art for the twelve module worlds.

- **Status:** *illustrator deliverable* (category 3 in `../../docs/design/ASSET_MANIFEST.md`).
  Layouts currently ship with **kit-built vector placeholders** (category 2) — the prototypes label
  these "final scene art: illustrator".
- **Governed by:** `../../docs/design/MODULE_WORLDS.md` — the **6-layer environment construction
  contract** (wash → far shapes → landmark & props → ground band → characters → UI), the 26-part
  shared kit, the ≥ 80% kit-reuse rule (≤ 4 unique assets per world), and per-world accent tokens.
- Every world's landmark, environment parts, props, and unique-asset list are enumerated there.

_No final environment files are included in this bundle yet; see `../prototypes/Module Worlds.dc.html`
for the kit and per-world storyboards._
