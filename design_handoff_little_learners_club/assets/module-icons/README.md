# assets/module-icons/

The twelve module **motif shapes** (petal, echo ring, leaf, brick, wave, steam curl, mat stripe,
crosswalk stripe, sun ray, pixel, compass diamond, mixed petals), the **map-node icons**, and the
**celebration particle** art.

- **Status:** *illustrator deliverable* (category 3 in `../../docs/design/ASSET_MANIFEST.md`).
  Current placeholders are colored geometric nodes / motif primitives (category 2).
- **Governed by:** icon rules in `../../docs/design/DESIGN.md §5` (24px grid, 2px ink stroke, rounded
  caps/joins, ≤ 2 shapes, active = filled accent/brand **plus a label**, no emoji) and the per-world
  `module.motif` enum in `../../docs/design/MODULE_WORLDS.md §3`.

_No final icon files are included in this bundle yet._
